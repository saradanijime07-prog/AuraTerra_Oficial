## Objetivos Scrum

### Product Goal
Consolidar una plataforma web integral, confiable y fácil de usar para la gestión, rehabilitación y seguimiento de fauna silvestre, centralizando el registro de ejemplares, el control de su estado de salud, el historial médico y la organización de hábitats con trazabilidad de datos para apoyar el trabajo diario del equipo.

### Sprint Goal
Entregar la base funcional y persistente de **AuraTerra** conectada a la base de datos (`auraterra_db`), con el modelo de entidades (`Animal`, `HistorialMedico` y `Habitat`), la precarga inicial segura de hábitats y la vista web operativa para registrar, consultar, buscar, editar, eliminar y paginar ejemplares.
